# additional_code_base

Додатковий код, що був використаний у магістерській роботі та не ввійшов до реалізації вебдодатка.
Програмна реалізація вебзастосунку доступна у репозиторії: https://github.com/ULiesnik/filters_in_frequency_domain

---

- Код порівняння реалізацій швидкого перетворення Фур'є та створення графіків із результатів - *fft_comparison.ipynb*
- Код для порівняння роботи частотних фільтрів та створення рисунків з результатами - *filters_comparison.ipynb*

---

  *Примітка: У файлі filters_comparison.ipynb збережено лише останні використані налаштування*
